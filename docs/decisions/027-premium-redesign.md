# 027: A premium redesign with no script: CSS motion, self-hosted fonts, real data drawn
**Date:** 2026-11-14
**Status:** Accepted. Lao asked for a complete premium redesign (Linear and Vercel in feel, GSAP or Motion for the animation) and approved the brief `research/redesign/RESEARCH.md` with "Yes, build it", every default.

## Context
The site was made plain on purpose on 2026-11-10 after Lao said it "looks super ai". The new request wanted more (a dark premium look, type, motion, a diagram, a server visualisation) and the same dislike (no generic AI template, no invented claims). The site also publishes promises that the code and tests enforce: `/cookies` says "the site runs no scripts", the README says nothing loads from outside, every answer carries `default-src 'none'`. GSAP, ScrollTrigger and Motion all need JavaScript.

## Decision
- **No script.** All motion is CSS, in the stylesheet's last block, behind `@media (prefers-reduced-motion: no-preference)`; scroll-driven rules (`animation-timeline`) also sit behind `@supports`. Scroll-driven animation is Baseline "newly available" since 2026-10-27 (Chrome and Edge 115, Firefox 159, Safari 26); elsewhere the page is simply still and complete. Two tests hold this: one block, last; every `animation-timeline` inside `@supports`. GSAP would have added about 46 KB gzipped, a `script-src`, a license notice (a non-OSI license inside an MIT repository) and a rewrite of the promise; it is not used. A pointer-following effect is the one thing lost.
- **Fonts are this site's own files.** Geist and Geist Mono (Latin, variable, OFL-1.1) from Fontsource 5.3.0, checked against the npm registry's integrity hash, 29.4 KB and 23.1 KB. The CSP gains `font-src 'self'` and nothing else; both policies stay equal and are pinned whole by a test. A fallback face in Arial, sized to Geist's own metrics (105.06% width, ascent 95.66%, descent 28.08%, measured with fontTools), keeps the swap from moving the page; every block measured the same with the fallback as with Geist.
- **Binary files get a field on `Page`.** `Page.bytes: Option<&'static [u8]>`; `body` stays a `&str` for every page, so no existing test changed shape. A font's address carries its fingerprint, so it is cached for a year as `immutable`.
- **The identity is one hairline and the logo.** The half-filled circle is the header's mark (inline SVG, so it takes the theme and can move), the footer's, the favicon and the server in the hero diagram. One green (`#5fe3a1` on dark, `#0a7c4a` on light, both checked at 4.5 to 1 against what they sit on). No gradient text, glass, blobs, icon tiles, emoji, lifting cards, stock images or uppercase kickers; two soft radial tints at most 8% strong (hero, closing band). The 2026-11-10 rules "system fonts only", "no motion" and "no gradient at all" end; the bans above stay.
- **Pictures are drawn in the pages and are decoration.** Every `<svg>` is `aria-hidden`; the words beside it (captions, verdicts) are the content. The hero diagram says "an illustration, not live data". The VPN off/on switch is a checkbox with `role="switch"` and `:has()`; both states are written out.
- **The one thing that never stops can be stopped.** The pulse along the hero's tunnel and the rings on the map's Up servers are the only endless animations; a "Pause motion" checkbox (shown only inside the motion block, so never to someone who asked for less) pauses them (WCAG 2.2.2). It is per page; a CSS toggle cannot remember.
- **The map draws the registry's own coordinates.** `status::map` projects each server's latitude and longitude (city level, the same the "Closest to you" rule uses) onto a 640 by 360 frame centred on the servers, with a whole-degree grid; the state is a class on the point; the words are in the list beside it. It carries no count, load, address or node name (decision 025 stands: the front page stays words only). A server with no coordinates is left off; with none, there is no map. On the front page and on `/status`.
- **The retention chart is tied to the code.** Five minutes, ten minutes, a day, 30 and 60 and 365 days, each bar `log10(minutes)` over the longest's; a test computes every number and every bar width from the constants (`FORGET_IDLE_AFTER_SECS`, `CODE_LIFETIME_SECS`, `KEEP_SECS`, the backup script's keep, `SESSION_LIFETIME_SECS`, `KEPT_SESSION_MAX_SECS`) and another checks that each "never kept" line is a line of the privacy policy.
- **The menu's "Get started" is for a visitor who is not in.** `for_visitor` drops it for a signed-in visitor on every public page and on a site with no sign-in side; the signed-in templates drop it with `{% block cta %}`. The admin invisibility test now compares a path with the same visitor's own 404.
- **Header and footer keep decision 018's way**: written out in every file and held equal by a test; the device page still empties its menu and links.

## Consequences
- The front page is 20 KB of HTML (6 KB gzipped), the stylesheet 41 KB (10 KB gzipped), the fonts 52 KB once and cached for a year; no script; two more requests than before, both preloaded.
- About a dozen existing tests changed with the markup (the header and footer, the sign-in swap strings, the SVG count on the device page, a `<li>` split, the reduced-motion test of the code field, the admin invisibility test), each with its reason in the test; 34 new ones.
- A change to a font, the stylesheet or the icon needs the `?v=` fingerprints re-stamped (tests name each address).
- The public export carries the fonts; the OFL permits it with the license text, which is in the folder.
- Older browsers get a complete still page: Firefox before 159 and Safari before 26 have no scroll-driven rules; Firefox has no page transitions; the FAQ's height animation is Chromium only; without `popover` the menu links wrap under the name.
- **Not done, on purpose:** GSAP or any script; a share image (added later the same day, decision 021 amended); per-visitor persistence of the pause switch; load, uptime or counts on the front page's map.
